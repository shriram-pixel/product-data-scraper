Product Scraper

Product names, prices and images from any Shopify, WooCommerce or Odoo store, with the spreadsheet to match.

Paste the store address. A full page URL is fine too.

Ready 

  
In Chrome and Edge, choose a folder once and a <store-name>/ folder is created inside it holding images/, products.xlsx and products.csv - the choice is remembered, so later runs go straight there. Firefox and Safari cannot write folders, so they download the same files as ZIPs.
